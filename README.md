# バーコードスキャナー → Googleスプレッドシート転記アプリ

スマホのカメラでバーコードをスキャンし、Googleスプレッドシートにリアルタイムで記録するWebアプリです。

## 動作の流れ

```
スマホブラウザ（カメラ） → GAS Webアプリ → Googleスプレッドシート
```

---

## セットアップ手順

### ステップ1: Googleスプレッドシートを用意する

1. [Google スプレッドシート](https://sheets.google.com) を開く
2. 「新しいスプレッドシート」を作成する
3. ファイル名を任意（例: `バーコード記録`）に変更する
4. このスプレッドシートを**開いたまま**にしておく

---

### ステップ2: GAS（Google Apps Script）を設定する

1. スプレッドシートのメニューから **「拡張機能」→「Apps Script」** をクリック

2. 左側のコードエリア（`function myFunction() {...}` という初期コード）を**全て削除**する

3. このリポジトリの **`Code.gs`** の内容を全てコピーして貼り付ける

4. 上部の **「保存」ボタン**（フロッピーアイコン）をクリック

5. 上部の **「デプロイ」→「新しいデプロイ」** をクリック

6. 以下のように設定する：
   | 項目 | 設定値 |
   |------|--------|
   | 種類の選択 | **ウェブアプリ** |
   | 説明 | バーコード受信（任意） |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |

7. 「デプロイ」をクリック

8. Googleアカウントの許可を求められたら **「許可」→「詳細」→「（プロジェクト名）に移動」→「許可」** の順に進む

9. 画面に表示される **「ウェブアプリURL」**（`https://script.google.com/macros/s/...` から始まるURL）をコピーして控えておく

---

### ステップ3: アプリをGitHub Pagesで公開する

1. このリポジトリを `ym-extensions/barcode-to-sheet` としてGitHub Pagesで公開する（Claudeが実行）

2. 公開URLをスマホのブラウザで開く

---

### ステップ4: スマホで初期設定する

1. スマホのブラウザでアプリのURLを開く（**Safari / Chrome 推奨**）

2. 「初期設定」欄に、ステップ2でコピーした **GAS WebアプリURL** を貼り付ける

3. 「保存」ボタンをタップ（次回から自動入力されます）

---

### ステップ5: スキャン開始

1. 「スキャン開始」ボタンをタップ → カメラ許可を「許可」する

2. バーコードをカメラにかざす → 自動で読み取り・送信

3. 画面に番号が大きく表示され「✅ スプレッドシートに記録しました」と出れば成功

4. スプレッドシートの「スキャン記録」シートに番号が追記されます

---

## 対応バーコード形式

| 形式 | 用途の例 |
|------|----------|
| CODE128 | **レターパック追跡番号**、宅配便 |
| EAN-13 / EAN-8 | 商品バーコード |
| CODE39 | 工業用タグ |
| ITF | ダンボール |
| QR Code | QRコード |

---

## オフライン時の動作

ネットワークが切れた状態でスキャンしても端末に一時保存され、オンラインに戻った瞬間に自動で再送します。

---

## トラブルシューティング

### カメラが起動しない
- HTTPSのURLで開いているか確認（GitHub Pagesは自動でHTTPS）
- ブラウザのカメラ許可を「許可」に設定する
- iPhoneの場合はSafariを使う（ChromeはiOSでカメラAPIが制限される場合あり）

### 「送信失敗」が続く
- GASのデプロイ時に「アクセスできるユーザー：全員」に設定されているか確認
- GASを再デプロイ（「新しいデプロイ」で新規作成）してURLを更新する
- GAS側のURLをアプリの設定画面で再保存する

### スプレッドシートに「スキャン記録」シートがない
- GASが初回受信時に自動作成します。まず1件スキャンしてみてください
